# 个人项目开发日志

## 一.配置读取

在yaml文件中写入配置，如何读取呢：三步走

第一步，写properties.yaml配置文件。
```
spring:
  application:
    name:
      VirtualAIBox

  virtual-clock:
    # 时间刻度，1秒 = 12虚拟秒
    tick: 12
    # 元时间：虚拟时钟的起始时间
    meta-instant: 2026-06-03T00:00:00+08:00
```

第二步，读取yaml。

@ConfigurationProperties注解规定了读取哪部分的配置信息。

@Data 是lombok中的注解，自动生成 getter、setter、toString、equals、hashCode。
```java
@Data
@ConfigurationProperties(prefix = "spring.virtual-clock")
public class VirtualClockProperties {

    private long tick;

    private Instant metaInstant;

}
```
第三步，将配置信息装配到Bean对象中，交由Spring控制。

@Configuration，底层是@Component，Spring启动时，会为@Component注解标记的类创建实例Bean。

@EnableConfigurationProperties(VirtualClockProperties.class)，将 VirtualClockProperties 注册为一个 Spring Bean。
```java
@Data
@Configuration
@EnableConfigurationProperties(VirtualClockProperties.class)
public class VirtualClockConfig {

    private final long tick;
    private final Instant metaInstant;

    public VirtualClockConfig(VirtualClockProperties properties) {
        this.tick = properties.getTick();
        this.metaInstant = properties.getMetaInstant();
    }
}
```

开发过程中遇到的问题：

**第一个问题**
```java
2026-06-08T21:04:33.096+08:00 ERROR 2752 --- [VirtualAIBox] [           main] o.s.boot.SpringApplication               : Application run failed

org.springframework.beans.factory.BeanCreationException: Error creating bean with name 'virtualClock' defined in file [D:\CodePackage\spring\VirtualAIBox\target\classes\com\own\virtualaibox\grid\VirtualClock.class]: Failed to instantiate [com.own.virtualaibox.grid.VirtualClock]: Constructor threw exception 
```
配置注入问题，Spring从yml文件读取配置信息到properties类，将properties注册为Spring Bean类，并注入到config类中。想要在其他类中使用配置时，注入即可。

错误写法：没有将properties注入到配置类中，导致无法获取配置信息。
```java
// 错误写法
@Data
@Component
@EnableConfigurationProperties(VirtualClockProperties.class)
public class VirtualClockConfig {

    private long tick;

    private Instant metaInstant;
}
```

**第二个问题**
```java
2026-06-08T21:04:33.096+08:00 ERROR 2752 --- [VirtualAIBox] [           main] o.s.boot.SpringApplication               : Application run failed

Caused by: java.lang.NullPointerException: Cannot invoke "com.own.virtualaibox.config.VirtualClockConfig.getMetaInstant()" because "this.clockConfig" is null
```
错误写法
```java
@Autowired
private VirtualClockConfig clockConfig;

private long metaDuration = clockConfig.getMetaInstant().getEpochSecond();
```
正确写法
```java
private final VirtualClockConfig clockConfig;

private final long metaDuration;

public VirtualClock(VirtualClockConfig clockConfig) {
    this.clockConfig = clockConfig;
    this.metaDuration = clockConfig.getMetaInstant().getEpochSecond();
}
```
使用@Autowired将config注入，但同时还从config取值，这导致config还来不及注入，实际为null。

我对于@Autowire注入和构造方法注入的理解是，如果要初始化的是静态的配置信息，用构造方法好一点（因为除了构造方法以外，其他时机来初始化都不太合理）；

如果是获取动态对象的内部数据，用注解注入代码更少、更优雅。
