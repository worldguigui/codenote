# 大模型基础-机器学习-深度学习

在几十年前，神经网络首次被发明时，最初的动机是模仿人类大脑或生物大脑是如何学习和思考的。

但如今的神经网络（neural networks），有时也称为人工神经网络（artificial neural networks），与我们实际大脑的工作和学习方式截然不同。

虽然我们在神经网络和生物中的神经元作过一些类比，但事实上，我们至今还对大脑的工作方式一无所知。

近些年，随着移动互联网的兴起，我们能够得到比以往多得多的数据。

研究人员发现，神经网络的规模越大，数据越多，性能越强。

将其运用到语音识别、图像处理、自然语言处理等领域，取得了以前的学习算法无法实现的性能，这导致了深度学习的兴起。

## 一.需求预测

我们可以将一个小的逻辑回归算法视为一个神经元模型。

我们可以把一个小的逻辑回归模型，视为一个神经元模型。

比如，我们现在想预测一件衬衫成为畅销品的概率。

原始特征有四个：**价格、运费、营销、材质**。

但我们凭直觉认为，决定畅销与否的更直接因素，可能是三个抽象概念：

- **可负担性** —— 主要取决于价格和运费  

- **高知名度** —— 主要取决于营销 
  
- **高质量** —— 主要取决于价格和材质  

我们可以分别设计**三个神经元**，各自完成一次逻辑回归：

- **神经元 1**：输入价格、运费 -> 输出“可负担性”的估计值

- **神经元 2**：输入营销 -> 输出“高知名度”的估计值  

- **神经元 3**：输入价格、材质 ->   输出“高质量”的估计值  

这三个神经元，共同构成了**一层（layer）**。

所谓**层**，就是一组神经元，它们接收相同或相似的一组特征作为输入，各自独立计算，然后并行输出一组数字。

每一个神经元输出的数字，就称为该神经元的**激活值**，它表示这个神经元从输入中“提取”出的某个信号强度。

这样，整个模型就形成了清晰的层次：

- **输入层**：就是原始特征本身 —— 价格、运费、营销、材质  

- **隐藏层**：上面那三个神经元所在的层，它们把原始特征“加工”成了更抽象的特征 —— 可负担性、高知名度、高质量 

- **输出层**：可以用最后一个神经元，把这三个抽象特征综合起来，最终输出这件衬衫成为畅销品的概率  

这里，输入层和隐藏层之间的连接不是全连接的：  

可负担性神经元只连接价格和运费，知名度和材质不连接它。  

## 二.神经网络层

大多数现代神经网络（neural network）的基本构建块，就是一层神经元。

我们用上标方括号来标记层号，比如 **[0]** 表示第 0 层，**[1]** 表示第 1 层，以此类推。

每一层神经元在做完线性组合之后，都会通过一个**激活函数g**来生成输出。这个输出称为该层的**激活值**。

现阶段，我们统一使用逻辑回归中的 **Sigmoid 函数**作为激活函数。

用大写字母 **A** 带上标来表示某一层的激活值：

- **A[0]**：第 0 层的激活值

回到衬衫的例子，就能这样对应：

- **A[0]** 就是**输入层**，也就是原始特征——价格、运费、营销、材质

- 它们本身也被视为激活值，只不过没有经过任何计算，直接就是数据

这一层是整个网络的起点，所有后续的特征提取都从它开始。

## 三.推理：预测与前向传播

推理，就是模型拿着数据去预测结果的过程

前向传播，就是从左到右，一层一层地计算激活值，最终在输出层得到预测结果的过程。

一个常见的规律是：**随着逐渐接近输出层，层中的神经元数量往往逐渐减少。**

- 输入层的神经元数量由原始特征个数决定，通常较大
  
- 隐藏层把特征逐步“压缩”和“提炼”，神经元数可以少于输入

- 输出层只保留最终任务所需的神经元数———二分类问题就只需要 1 个

### 以衬衫模型为例

结合前面的例子，前向传播的完整计算过程如下：

**第 0 层（输入层）**  

A[0] 直接就是原始特征，不做任何计算：

```
A[0] = [价格, 运费, 营销, 材质]   4 个激活值
```

**第 1 层（隐藏层）**  

三个神经元各自做线性组合，再用 Sigmoid 激活：

```
可负担性 = g( w₁×价格 + w₂×运费 + b₁ )
高知名度 = g( w₃×营销 + b₂ )
高质量   = g( w₄×价格 + w₅×材质 + b₃ )
```

这一层的激活值 A[1] 就是这三个输出组成的向量：

```
A[1] = [可负担性, 高知名度, 高质量]   3 个激活值
```

可以看到，4 个原始特征被提炼成了 3 个抽象特征。

---

**第 2 层（输出层）**  

最后一个神经元综合 A[1] 的三个值，输出畅销概率：

```
畅销概率 = g( w₆×可负担性 + w₇×高知名度 + w₈×高质量 + b₄ )
```

A[2] 就是最终输出：

```
A[2] = [畅销概率]   1 个激活值
```

## 五.单层前向传播
### 1.第一层：从输入 \(\vec{x}\) 到 \(\vec{a}^{[1]}\)

第一层有 3 个神经元，每个神经元独立计算：

\[
a_1^{[1]} = g(\vec{w}_1^{[1]} \cdot \vec{x} + b_1^{[1]})
\]

\[
a_2^{[1]} = g(\vec{w}_2^{[1]} \cdot \vec{x} + b_2^{[1]})
\]

\[
a_3^{[1]} = g(\vec{w}_3^{[1]} \cdot \vec{x} + b_3^{[1]})
\]

```python
# 完整的计算过程

w1_1 = np.array([1, 2])      
w1_2 = np.array([-3, 4])     
w1_3 = np.array([5, -6])

b1_1 = np.array([-1])        
b1_2 = np.array([1])          
b1_3 = np.array([2])

z1_1 = np.dot(w1_1, x) + b1_1   
z1_2 = np.dot(w1_2, x) + b1_2   
z1_3 = np.dot(w1_3, x) + b1_3

a1_1 = sigmoid(z1_1)            
a1_2 = sigmoid(z1_2)             
a1_3 = sigmoid(z1_3)

a1 = np.array([a1_1, a1_2, a1_3])
```

### 2.第二层：从 \(\vec{a}^{[1]}\) 到 \(a^{[2]}\)

第二层有 1 个神经元，汇总第一层的输出：

\[
a^{[2]} = g(\vec{w}_1^{[2]} \cdot \vec{a}^{[1]} + b_1^{[2]})
\]

- \(\vec{a}^{[1]}\) 是第一层提取出的三个抽象特征
- \(a^{[2]}\) 是最终输出，比如“好喝概率”
### 3.激活函数：从 \(z\) 到 \(a\)

\[
a = g(z) = \sigma(z) = \frac{1}{1 + e^{-z}}
\]

- \(z\) 越大，\(\sigma(z)\) 越接近 1
- \(z\) 越小，\(\sigma(z)\) 越接近 0
- \(z = 0\) 时，\(\sigma(0) = 0.5\)


### 4. 整个前向传播的完整计算链

\[
\underbrace{\vec{x}}_{\text{原始输入}}
\;\xrightarrow{\vec{w}^{[1]}, b^{[1]}}\;
\underbrace{\vec{z}^{[1]}}_{\text{第一层线性}}
\;\xrightarrow{\sigma}\;
\underbrace{\vec{a}^{[1]}}_{\text{第一层激活}}
\;\xrightarrow{\vec{w}^{[2]}, b^{[2]}}\;
\underbrace{z^{[2]}}_{\text{第二层线性}}
\;\xrightarrow{\sigma}\;
\underbrace{a^{[2]}}_{\text{最终输出}}
\]

每一步都是确定的、可重复的，没有循环，没有反馈，因此叫**前向**传播。这就是神经网络做一次预测的完整数学过程。

## 六.前向传播的通用实现

我们可以将之前单个神经元的公式，抽象成一个可复用的 dense 函数，从而搭建任意层数的网络。

考虑这么一个密集函数dense(a_in,w,b)，接收前一层的激活值、wb参数，输出下一层的激活值。

给定密集函数，我们就可以按顺序连接几个密集层，实现前向传播。

```python
def dense(a_in,w,b):
    units = w.shape[1]
    a_out = np.zeros(units)
    for j in range(units):
        w = w[:,j]
        z = np.dot(w,a_in) + b[j]
        a_out[j] = g(z)
    return a_out
```

### 1.向量化
在dense函数中，我们通过循环loop逐个神经元计算，但这可以很方便得转化为向量计算。

def dense(a_in,w,b):

### 4.Sigmoid的替换
线性激活函数g(z) = z，Linear Activation function，当处理回归问题时，预测结果是正数或负数。

Sigmoid激活函数，当处理二分类问题时，预测结果在0到1之间。

修正线性单元g(z) = max(0,z)，Rectified Linear Units，ReLU，当预测结果为非负数时。是目前隐藏层的默认选择（因为这通常会更快）。

### 5.为什么需要激活函数？
我们可能在想，为什么需要如何多样的激活函数，只使用线性激活函数不行吗？

答案当然是不可以。

如果所有层都使用线性激活函数，无论堆叠多少层，最终模型仍然等同于一个线性回归模型。

没有非线性激活函数，再深的网络也无法学习复杂模式，那将毫无意义。

## 八.多类别问题
多类别问题是指分类结果多于两个类别（如手写数字识别 0-9）。

这和之前的二分类问题不同，因此，我们要学习另一个激活函数，它是对Sigmoid的泛化。 

### 1. Softmax 激活函数

Softmax 是 Sigmoid 在多类别上的泛化。它接收一个向量 \( \vec{z} = [z_1, z_2, \dots, z_N] \)，输出一个概率分布 \( \vec{a} = [a_1, a_2, \dots, a_N] \)，满足每个 \( a_j \in (0,1) \) 且 \( \sum a_j = 1 \)。


\[
a_1 = \frac{e^{z_1}}{e^{z_1} + e^{z_2} + \dots + e^{z_N}}
\]

\[
a_2 = \frac{e^{z_2}}{e^{z_1} + e^{z_2} + \dots + e^{z_N}}
\]

\[
\vdots
\]

\[
a_N = \frac{e^{z_N}}{e^{z_1} + e^{z_2} + \dots + e^{z_N}}
\]

**公式**：

\[
a_j = \frac{e^{z_j}}{\sum_{k=1}^{N} e^{z_k}}
\]

### 2.具体示例
假设输出层线性结果 \( \vec{z} = [2.0, 1.0, 0.1] \)，计算 Softmax：

1.  **计算分子** \( e^{z_j} \)：
    -   \( e^{2.0} \approx 7.389 \)
    -   \( e^{1.0} \approx 2.718 \)
    -   \( e^{0.1} \approx 1.105 \)

2.  **计算分母**（所有分子之和）：
    -   \( 7.389 + 2.718 + 1.105 = 11.212 \)

3.  **计算概率**：
    -   \( a_1 = 7.389 / 11.212 \approx 0.659 \)
    -   \( a_2 = 2.718 / 11.212 \approx 0.242 \)
    -   \( a_3 = 1.105 / 11.212 \approx 0.099 \)

输出 \( \vec{a} \approx [0.659, 0.242, 0.099] \)，三个概率之和为 1，模型预测类别为概率最高的第 0 类。

### 3.代码实现
```python
model = Sequential([
    # layer1
    Dense(units=25, activation="relu"),
    # layer2
    Dense(units=15, activation='relu")
    # layer2
    Dense(units=10, activation='softmax")
])

model.compile(loss=SparseCategoricalCrossentropy())

model.fit(x,y,epochs=100)
```

### 4.数值准确版本
Softmax 计算中 \( e^{z} \) 容易导致数值溢出。更准确的做法是让输出层先计算线性值 \( z \)（不加激活），再在损失函数中结合 Softmax 一起计算。

```python
# 输出层不要激活函数
Dense(units=10, activation="linear")

# 损失函数内部处理 Softmax
model.compile(loss=SparseCategoricalCrossentropy(from_logits=True))
```

from_logits=True 告诉损失函数输入是未经 Softmax 的原始值，内部会用数值稳定的方法计算，结果更精确。
### 5.多标签分类问题
多标签分类，就是说一个样本可以同时属于多个类别。例如给电影打标签，一部电影可以既是“科幻”又是“动作”。

使用 Sigmoid 激活函数作为输出层，每个神经元独立输出 0~1 的概率。

与多类别（Softmax）不同，Softmax 强制各类别概率之和为 1，只能选一个；多标签则互不排斥，允许同时选多个。

我们想要判别一个电影的标签，特征有[科幻, 动作, 喜剧, 恐怖].

输出层的结果可能是，[0.96,0.18,0.57,0.06]，它们的总和不为1，这表示这个电影有两个标签：科幻和喜剧。

## 九.高级优化
其实，有一些算法也能够最小化代价函数，并且速度比梯度下降还要快。

对于梯度下降算法来讲，计算过程中，参数w被更新为wj减去学习率alpha乘以对w的偏导。

### 1.adam算法

adam算法是一种可以根据梯度下降的进展情况，自动调节学习率的算法。

adam的原理可以这样理解，对于参数wb，如果它们一直在一个大致相同的方向上移动，我们就调大学习率；如果它们一直在震荡，我们就缩小学习率。

### 2.代码实现
```python
model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=1e-3),
              loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logics=True))

model.fit(x,y,epochs=100)
```

## 十.额外的层结构
### 1.卷积层

卷积层，Convolutional Neural Network，是卷积神经网络（CNN）的核心组件。

与全连接层不同，它的每个神经元只连接输入的一小块局部区域，并通过共享权重来检测相同的模式（如边缘、纹理），无论该模式出现在图像的哪个位置。

在大模型基础中，不要求完全掌握这些知识（这实际上是卷积层与卷积神经网络里的内容），只是提供另一种视野，

很多神经网络的研究只是研究者发明了全新的层结构，并把多种类型的层组合在一起，形成一个更复杂且希望更强大的神经网络。

### 1.训练集和测试集
将原始数据分为两个子集：

训练集：用于训练模型，调整参数。

测试集：用于评估模型在未见过的数据上的泛化能力。

### 2.模型选择与训练、交叉验证、测试集

实际开发中，我们通常需要比较不同模型（如不同层数、神经元数）。

若直接用测试集选模型，会导致模型对测试集过拟合。

因此引入交叉验证集，一个额外的数据集，用来检查或交叉检查不同模型的有效性或准确性。
